Tentang saya

Saya adalah seseorang yang memiliki ketertarikan pada dunia teknologi, khususnya coding dan game. Bagi saya, keduanya bukan hanya sekadar hobi, tetapi juga menjadi cara untuk mengembangkan kemampuan berpikir logis, kreativitas, dan problem solving.

Saya menikmati proses coding karena setiap masalah memberikan kesempatan untuk belajar dan menemukan solusi baru. Saya senang mencoba berbagai hal, membuat project sederhana, serta terus mempelajari teknologi dan konsep baru untuk meningkatkan kemampuan saya.

Di waktu luang, saya juga suka bermain game. Dari bermain game, saya belajar tentang strategi, ketelitian, pengambilan keputusan, serta pentingnya mencoba kembali ketika menghadapi kegagalan. Hal tersebut secara tidak langsung membantu saya dalam menghadapi tantangan ketika mengerjakan sebuah project.

Saya percaya bahwa belajar tidak harus selalu terasa seperti belajar. Dengan menggabungkan hal yang saya sukai dengan teknologi, saya ingin terus berkembang, menghasilkan karya yang bermanfaat, dan membangun pengalaman di bidang yang saya minati.
